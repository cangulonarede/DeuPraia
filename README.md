# DeuPraia! — widget de marés de Natal/RN

Projeto Android de widget com consulta à API Tábua de Marés, atualizado por GitHub Actions.

## Alterações visuais
- Cabeçalho Natal · RN com símbolo de ondas.
- Duas colunas para Hoje e Amanhã.
- Indicadores triangulares vetoriais: azul para maré alta e vermelho para maré baixa.
- Horários em destaque e etiquetas coloridas sem emojis.
- Botão para atualizar os dados.

## Compilação
Faça commit das alterações no repositório GitHub `MaresDeNatal` e acompanhe a execução em Actions. O workflow deve publicar o APK como artefato.
